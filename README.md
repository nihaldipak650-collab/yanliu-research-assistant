## 三个方向

- **文献与综述：**沿用用户的阅读、表格和写作习惯，衔接研究、交付与修订。
- **科研日报：**围绕课题连接论文、新闻与开源工具，减少额外调研。
- **ImageJ：**用自然语言复用图像分析流程，保留人工检查和结果导出。

## 真实使用进展

- **综述：**2 位正式使用者、4 位意向试用者。按当前使用反馈估计，这套方式承担约 80% 的工作，后续由导师和研究者修改。
- **日报：**3 位预试用者，分别为 2 位导师、1 位学生。
- **SG 计数对照：**人工 37，AI 35。
